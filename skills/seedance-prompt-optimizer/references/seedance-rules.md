# Seedance 2.0 提示词优化规则

这些规则汇总自 Seedance 2.0 常见问题、官方提示词指南和本工具的自动化规则，是随技能发布的最高优先级参考。

## 优先规则

- 使用清晰的任务措辞：`参考` 表示从素材中提取元素并生成新视频，`严格编辑视频N` 表示修改原视频，`延长/向前延长视频N` 表示延续原视频。
- 编辑和延长任务不要写 `参考视频N`，应直接要求模型编辑或延长 `视频N`。
- 轨道补齐、补音频、补声音、补口型归入编辑任务：写 `严格编辑视频N，只补齐目标音频/口型/轨道内容，其余主体、动作、场景、构图、光影和时长保持不变`。
- 前序生成归入延长任务：写 `向前延长视频N，生成视频N之前自然发生的内容`，并尽量使用视频首帧作为衔接锚点；向后延长使用尾帧作为衔接锚点。
- 使用按时间顺序组织的分镜结构。优先写 `镜头1/镜头2/...`，不要把剧情堆成一整段。除非用户明确需要精确时间，否则不要强行给每个镜头限定秒数。
- 多模态提示词需要在开头声明每个编号素材的职责，并在分镜中重复绑定，例如 `Nora@图片1`。
- 如宿主模型已经理解了素材，应把结构化摘要转成明确职责：图片写主体/场景/风格，视频写首尾帧/运镜/动作/节奏，音频写音色/情绪/节奏。CLI 只消费摘要，不直接读取真实媒体或调用外部 API。
- Asset ID 不是模型可理解的参考名称，必须显式映射到 `图片N/视频N/音频N`。
- 如果用户粘贴 Seedance API 风格 `content` JSON，应按非文本素材出现顺序映射为 `图片N/视频N/音频N`，并把文本中的 Asset ID 或 URL 替换为这些编号引用。
- 断句防歧义：`@图片N`、`@视频N` 后尽量跟角色名或名词解释，例如 `@图片1（女主）走向镜头`，不要写成 `@图片1走向镜头`。
- 每个镜头只保留一种主要运镜；同一镜头同时出现推、拉、摇、移、环绕、固定等多个互斥运镜时，应提示用户确认。
- 长图、九宫格、拼图、多视图参考会增加识别混乱风险，建议拆成单张素材后逐一绑定。
- 避免使用 `--`；Seedance 可能不解析该符号之后的内容。

## 好提示词结构

默认按三段论格式组织：

1. `整体设定：` 写世界观/场景、主体外观、空间环境、光影色调、情绪氛围；如有素材，在这一段写清 `@图片1是...，@视频1是...，@音频1是...`。
2. `时间片分镜：` 下使用 `镜头1:`、`镜头2:` 连续句式；每个镜头在一句或数句中写景别/机位/镜头、主体动作、场景光影和配音/音效。
3. `风格画质约束：` 写视觉风格、动作稳定、字幕/文字、logo/水印、BGM/音效等全局约束。
4. 不使用字段化的 `【镜头1】`、`- 景别/机位/镜头：`、`- 主体/动作：` 模板，除非用户明确要求。

## 常见诊断

- 缺少分镜：没有清晰镜头顺序的提示词，对 Seedance 来说属于明显问题提示词。
- 缺少多模态绑定：素材必须在开头和分镜中与文字明确关联。
- 缺少素材理解摘要：已上传素材但没有文字职责或摘要时，模型只能猜素材用途；应补充 `图片N/视频N/音频N` 的结构化理解。
- 视频摘要不足：编辑/延长任务中，视频摘要缺少首尾帧或运镜信息时，衔接和保真风险更高。
- content JSON 映射：检测到 API 风格输入时，需要建立 Asset ID/URL 到 `图片N/视频N/音频N` 的映射。
- 运镜冲突：同一镜头存在多种互斥运镜，容易造成画面不稳定。
- 素材引用歧义：`@图片N` 直接连接动作或方位，容易被误解为数量或位置关系。
- 长图/九宫格风险：多画面拼在一张参考图内会降低参考稳定性。
- 表述过虚：将 `氛围感`、`电影感`、`好看点`、`高级感` 等词替换为具体光线、色彩、构图、动作或风格细节。
- 无效画质词：不要依赖 `4K`、`60fps`、`HDR` 等词作为控制手段。
- 字幕风险：不需要可见文字时添加 `保持无字幕，避免画面生成字幕`；这只能降低概率，不能保证 100% 无字幕。
- logo/水印风险：添加 `不要生成logo，不要生成水印`。
- 风格漂移：明确目标风格，例如 `2D日漫风格`、`3D国风漫画`、`真人写实` 等。
- 人物 ID 漂移：角色身份重要时，尽量使用独立人脸特写参考；不要只用多视图拼图作为人物参考。
- 双胞胎问题：多人场景中明确禁止重复同脸人物、复制人物或分身效果。
- 音色风险：使用音频参考时，在文字中补充音色和说话风格，并让生成台词风格尽量贴近参考音频。

## 符号规范

- 音乐：`（背景中播放着快节奏的摇滚乐）`
- 音效：`<远处传来狗叫声>`
- 台词：`{你好，世界}`；小语种台词需要标注语种。
- 字幕：`【第一章：启程】`
- 时长使用中文 `秒`，不要写 `s`。

## 任务模板

参考：

```text
参考@图片1中的主体，生成...
参考@视频1中的动作/运镜/风格/音效，生成...
参考@音频1中的音色，生成...
```

编辑：

```text
严格编辑视频1，将其中的[原特征]修改为[新特征]，其余内容保持不变。
```

延长：

```text
延长视频1，生成...
向前延长视频1，生成...
```

轨道补齐：

```text
严格编辑视频1，只补齐音频轨道/口型/目标轨道内容，其余主体、动作、场景、构图、光影和时长保持不变。
```

组合：

```text
参考@图片1的[参考维度]，严格编辑视频2，[具体编辑内容]。
```
