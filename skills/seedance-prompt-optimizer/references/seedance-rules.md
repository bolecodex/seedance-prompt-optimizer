# Seedance 2.0 提示词优化规则

这些规则基于仓库中的 Seedance 文档整理而成。如有冲突，以 `docs/Seedance 2.0提示词常见问题与处理指南.md` 为最高优先级。

## 优先规则

- 使用清晰的任务措辞：`参考` 表示从素材中提取元素并生成新视频，`严格编辑视频N` 表示修改原视频，`延长/向前延长视频N` 表示延续原视频。
- 编辑和延长任务不要写 `参考视频N`，应直接要求模型编辑或延长 `视频N`。
- 使用按时间顺序组织的分镜结构。优先写 `镜头1/镜头2/...`，不要把剧情堆成一整段。除非用户明确需要精确时间，否则不要强行给每个镜头限定秒数。
- 多模态提示词需要在开头声明每个编号素材的职责，并在分镜中重复绑定，例如 `Nora@图片1`。
- Asset ID 不是模型可理解的参考名称，必须显式映射到 `图片N/视频N/音频N`。
- 避免使用 `--`；Seedance 可能不解析该符号之后的内容。

## 好提示词结构

按这个顺序组织：

1. `【全局设定】`：任务、风格、必要时长/比例、场景、光线、色调，以及全局音频/文字策略。
2. `【全局设定】` 内写 `多模态参考`：逐一说明图片、视频、音频的职责；能拆分职责时，尽量让每个素材只承担一种主要职责。
3. `【镜头N】`：按文档字段写 `景别/机位/镜头`、`主体/动作`、`场景/光影`、`风格/画质`、`配音/音效`、`约束`。
4. `【全局约束】`：不需要字幕/文字时明确禁止，补充不要 logo/水印、面部和身体稳定、不要重复同脸人物、动作自然、无闪烁等约束。

## 常见诊断

- 缺少分镜：没有清晰镜头顺序的提示词，对 Seedance 来说属于明显问题提示词。
- 缺少多模态绑定：素材必须在开头和分镜中与文字明确关联。
- 表述过虚：将 `氛围感`、`电影感`、`好看点`、`高级感` 等词替换为具体光线、色彩、构图、动作或风格细节。
- 无效画质词：不要依赖 `4K`、`60fps`、`HDR` 等词作为控制手段。
- 字幕风险：不需要可见文字时添加 `保持无字幕，避免画面生成字幕`；这只能降低概率，不能保证 100% 无字幕。
- logo/水印风险：添加 `不要生成logo，不要生成水印`。
- 风格漂移：明确目标风格，例如 `2D日漫风格`、`3D国风漫画`、`真人写实` 等。
- 人物 ID 漂移：角色身份重要时，尽量使用独立人脸特写参考；不要只用多视图拼图作为人物参考。
- 双胞胎问题：多人场景中明确禁止重复同脸人物、复制人物或分身效果。
- 音色风险：使用音频参考时，在文字中补充音色和说话风格，并让生成台词风格尽量贴近参考音频。

## 符号规范

- 音乐：`（背景中播放着快节奏的摇滚乐）`
- 音效：`<远处传来狗叫声>`
- 台词：`{你好，世界}`；小语种台词需要标注语种。
- 字幕：`【第一章：启程】`
- 时长使用中文 `秒`，不要写 `s`。

## 任务模板

参考：

```text
参考@图片1中的主体，生成...
参考@视频1中的动作/运镜/风格/音效，生成...
参考@音频1中的音色，生成...
```

编辑：

```text
严格编辑视频1，将其中的[原特征]修改为[新特征]，其余内容保持不变。
```

延长：

```text
延长视频1，生成...
向前延长视频1，生成...
```

组合：

```text
参考@图片1的[参考维度]，严格编辑视频2，[具体编辑内容]。
```
